# CANFIDS plugin downloads

This is the download page for **CANFIDS**, the EuroScope plugin that shows flight-plan route and
altitude verdicts for Canadian FIRs (the FPC and NAV list columns and the detail window).

**Get the latest version:** [Releases → Latest](https://github.com/imreiji/CANFIDS-releases/releases/latest).
Each release has `CANFIDS.dll` attached, with release notes and the file's SHA-256.

## Installing

1. Download `CANFIDS.dll` from the latest release.
2. Replace the copy your sector package loads (for CZQM: `CZQQ\Plugins\CANFIDS\CANFIDS.dll`).
   Close EuroScope first - a loaded DLL cannot be replaced.
3. Start EuroScope. When a newer version is out, the plugin says so once in chat, with this link.

## About this repository

It holds release notes and binaries only. The plugin's source is not public yet; it is planned to
be opened with the public beta. Releases contain no navigation data.
